# 飞书文档导出工具

将当前飞书文字文档保存为 **Markdown、HTML、PDF 或已采集素材 ZIP**。首个公开版本为 **0.0.1**。

点击页面右侧的小下载圆钮，选择格式后点“保存到本地”。无需 Token、本机服务或额外应用。界面跟随页面配色，任务期间显示进度，完成后恢复阅读位置。

## 安装

1. 安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。在浏览器要求时，开启扩展的“允许用户脚本”。
2. 打开 [安装脚本](https://raw.githubusercontent.com/sisttri/lark-doc-exporter/main/lark-doc-exporter.user.js)，按油猴提示安装。也可以从发布包导入安装 ZIP。
3. 等待油猴完成两项 PDF 资源的下载和校验，再刷新飞书文字文档。

如果此前安装了内部测试脚本“飞书本地保存”，请先关闭旧脚本，避免两个入口互相干扰。当前名称和首发版本号与内部测试版不同，需要手动迁移。

主脚本保持小于 Greasy Fork 的 2 MB 限制。**首次安装仍需下载约 30 MB 的 PDF 引擎和完整中文字库**，这些静态资源由油猴缓存。选择 Markdown、HTML 或素材包时不会读取、解析字库，也不会启动 PDF Worker。完整字库用于保留中文字符覆盖和粗体效果，并非删除了字库内容来减小体积。

## 使用

- **Markdown**：下载包含 `.md` 与正文图片的 ZIP；解压后保持目录结构。带样式、合并或无表头表格用静态 HTML 保留结构与样式，需要阅读器支持 HTML 和内联样式。
- **HTML**：下载可离线打开的单个网页，内嵌图片，宽表和代码可局部滚动；较长多章节文档提供折叠目录。
- **PDF**：下载浏览器内生成的 A4 文本 PDF，内嵌中文常规、粗体字体，代码使用 Courier 等宽字体。
- **素材包**：下载已采集图片及清单。文档中的文件链接会说明原件未采集。

多选时生成一个总 ZIP，包含所选格式及实际文件清单。保存目录、是否询问地址、同名文件处理均跟随浏览器设置。

采集时页面会自动滚动。关闭浮层或按 Esc 会收起进度，任务继续；重新点击圆钮可查看。点“取消保存”才会停止任务。完成后可从“上次文件”重新下载；“补存其他格式”明确复用上次采集内容，默认“保存到本地”会重新读取文档。

## 范围与限制

覆盖 `*.feishu.cn` 各租户的 `/docx/`、`/docs/`、`/wiki/` 文字文档。电子表格、多维表格、幻灯片和文件预览不属于支持范围。仓库名中的 Lark 不表示已适配 `larksuite.com`。

采集读取当前会话的页面内容、已加载图片及画板场景，不自行调用飞书 OpenAPI 或下载接口，不绕过登录。代码、表格及同步引用有有界复核；无法确认完整、内容在读取期间发生变化或发生转换降级时，面板和文件会提示核对。

- 公式和不支持的图形使用可用文字或占位降级。
- 画板优先按当前已加载场景的原始坐标离屏重绘 PNG，保留文字、线条和明确底色，不依赖当前预览尺寸。原生能力不可用时，尝试预览重绘并恢复本地显示样式，受限预览在图片说明中标注。PNG 受像素预算限制，不包含可编辑节点、交互或未加载内容。
- 在线附件原件、评论、权限和历史版本不包含在结果中。
- PDF 保留已采集图片的原始像素，长图按正文宽度连续分段排版；非常宽的 PDF 表格可能按行降级。
- DOM 读取不提供协作文档的原子版本快照，持续编辑时需要重新保存核对。
- `/docs/` 已有路由回归，仍需更多真实旧版页面样本。

图片、画板和表格的保存规则与格式差异见 [导出质量规则](docs/export-quality.md)。

表格优先保留原列宽比例、单元格底色及水平/垂直对齐；深色底色同时保留文字对比色。PDF 按纸张可用宽度适配，过窄列保留最低可读宽度；单元格自身内容跨页时，垂直对齐按引擎的流式分页处理。样式读取有缓存，复用现有内容复核流程。

## 数据与资源

文档正文、图片、转换和打包留在当前浏览器中，不上传到本项目服务器。本项目没有服务器、统计或遥测。

安装或更新脚本时，油猴会访问 GitHub 下载主脚本和两个静态 PDF 资源。资源 URL 固定到 Git commit，使用 SHA-256 SRI，并在生成 PDF 前再次校验缓存内容。PDF 运行时只读取 `GM_getResourceText` 预缓存，不从网络补拉依赖；缓存缺失或损坏会提示重新安装。页面自身的网络请求以及你主动点击的普通链接由飞书和浏览器处理。

画板原生路径通过油猴的 `unsafeWindow` 读取当前页面提供的本地渲染能力，并核对文档、画板和 DOM 归属；能力不匹配时回退到页面预览。脚本不新增账号授权、Token 配置或服务端。

格式选择和圆钮位置使用站点本地偏好；正文及导出文件不写入这些偏好。生成结果保存在页面临时内存，刷新或切换文档后释放。

## 开发与构建

需要 Node.js 22 或更高版本。只保留页内导出的采集、校验、格式生成和保存路径，不包含本地工作台、目录缓存或命令行采集工具。

```sh
npm ci
npm run build
npm test
```

输出为 `lark-doc-exporter.user.js` 和 `飞书文档导出工具-0.0.1.zip`。构建强制检查主脚本体积、固定 commit 资源地址、本地资源摘要及油猴编辑器默认静态规则，自有代码不压缩。也可用 `npm run lint` 单独检查最终脚本；ESLint 仅用于开发，不打入插件。第三方库的合法风格例外限定在各上游模块内，自有代码继续完整检查。

更新 PDF 引擎或字体时，先运行 `npm run build:assets`。校验并提交 `release-assets/` 后，将 `pdf-resource-manifest.json` 指向该提交的固定 URL 和摘要，再构建主脚本。不要删除历史资源提交。资源说明见 [release-assets/README.md](release-assets/README.md)。

解析器 parse5 使用 ES Module 结构；fflate 也用于隔离 Worker 内的解压。为保留模块边界并避免运行时加载代码，相关依赖以内联可读形式构建，产物标明版本与来源；独立 PDF 引擎则使用带 SRI 的静态资源。

源码分工：`userscript/capture.js` 采集页面，`importer.js` 校验内存快照，`formats.js` 生成 Markdown/HTML/ZIP，`pdf.js` 定义 PDF 排版，`userscript/pdf.js` 管理缓存资源与可取消 Worker，`userscript/entry.js` 管理浮层和保存流程。
