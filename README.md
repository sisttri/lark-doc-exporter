# 飞书文档导出工具

将当前飞书文字文档保存为 **Markdown、HTML、PDF 或已采集素材 ZIP**。首个公开版本为 **0.0.1**。

点击页面右侧的小下载圆钮，选择格式后点“保存到本地”。无需 Token、本机服务或额外应用。界面跟随页面配色，任务期间显示进度，完成后恢复阅读位置。

## 安装

1. 安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。在浏览器要求时，开启扩展的“允许用户脚本”。
2. 打开 [安装脚本](https://raw.githubusercontent.com/sisttri/lark-doc-exporter/main/lark-doc-exporter.user.js)，按油猴提示安装。也可以从发布包导入安装 ZIP。
3. 等待油猴完成两项 PDF 资源的下载和校验，再刷新飞书文字文档。

如果此前安装了内部测试脚本“飞书本地保存”，请先关闭旧脚本，避免两个入口互相干扰。当前名称和首发版本号与内部测试版不同，需要手动迁移。

主脚本保持小于 Greasy Fork 的 2 MB 限制。**首次安装需缓存合计约 32.5 MB 的两项 PDF 资源**：PDF 引擎和字体包。字体包含完整中文常规、粗体，以及有限 emoji 和符号回退字体。选择 Markdown、HTML 或素材包时不解析字库，也不启动 PDF Worker。

## 使用

- **Markdown**：下载包含 `.md`、正文图片和成功采集附件的 ZIP；解压后保持目录结构。复杂表格用静态 HTML 保留结构与样式，需要阅读器支持 HTML 和内联样式。
- **HTML**：下载可离线打开的单个网页，内嵌图片及成功采集的附件，附件可从正文链接保存。宽表和代码可局部滚动；较长多章节文档提供折叠目录。
- **PDF**：下载浏览器内生成的 A4 文本 PDF，内嵌中文常规、粗体和有限 emoji、符号字体。代码使用 Courier 等宽字体；文件附件显示名称，不嵌入 PDF。需要原件时同时选择素材包。
- **素材包**：下载已采集图片、附件原件及清单；未取得原件的附件保留缺失提示。

多选时生成一个总 ZIP，包含所选格式及实际文件清单。保存目录、是否询问地址、同名文件处理均跟随浏览器设置。

采集时页面会自动滚动。关闭浮层或按 Esc 会收起进度，任务继续；重新点击圆钮可查看。点“取消保存”才会停止任务。完成后可从“上次文件”重新下载；“补存其他格式”明确复用上次采集内容，默认“保存到本地”会重新读取文档。

“已交给浏览器保存”表示已发起下载，不表示浏览器已写完磁盘。页面能观察到的下载阻止或取消会显示失败，并允许复用已生成文件重试。浏览器接管后，在原生保存弹窗或下载管理器中取消，页面无法可靠获知。

## 范围与限制

覆盖 `*.feishu.cn` 各租户的 `/docx/`、`/docs/`、`/wiki/` 文字文档。电子表格、多维表格、幻灯片和文件预览不属于支持范围。仓库名中的 Lark 不表示已适配 `larksuite.com`。

采集读取当前会话的页面内容、原生块模型和渲染能力，并按原生文件配置请求高清图片及附件。请求使用当前浏览器会话，不需要手工配置 OpenAPI Token，也不绕过登录或下载权限。代码、表格、同步引用及块树有有界复核；无法确认完整、内容在读取期间发生变化或发生转换降级时，面板和文件会提示核对。

- 普通图片优先请求本块原生高清资源，保留实际返回的 PNG、JPEG、GIF 或 WebP 编码字节。这不保证与用户最初上传的文件完全相同。失败时回退到已加载位图的实际像素，不改写图片 URL 来猜测原图。
- 图片图注和画板说明从可识别的源结构读取，保留文本和已有换行。未知图注结构会提示核对。
- 画板优先按当前已加载场景的原始坐标离屏重绘 PNG，保留文字、线条和明确底色。主渲染不可用时，再尝试具有可信完整边界的隔离代理；边界无法确认时不请求完整场景。其后尝试预览重绘，恢复本地显示样式并标明受限预览。PNG 不包含可编辑节点、交互或未加载内容。
- 流程图（`diagram`）保存经过静态校验的 SVG 主素材，供 HTML、Markdown 和素材包使用。PDF 使用同一素材的高清 PNG 回退，保留 SVG 中的静态文字标签；不支持的主动内容、外部引用或超出预算的结构会提示缺图。
- 公式保留可复制的 LaTeX 源码；普通公式的 Markdown 使用数学定界符，HTML 和 PDF 显示源码。已识别的 Mermaid 插件保留代码，时间线按条目输出，文档提及保留文字及安全链接。不包含数学排版或 Mermaid 渲染引擎。
- 嵌套列表保留父子层级、混合列表类型及各层独立编号。Callout 保留自身文字和内部已支持的图片、代码、表格、列表等内容；分栏按原文栏序线性展开。跨视口采集会合并已知容器内的子块，无法确认位置时提示核对。
- 已就绪且可安全定位的简单正文块，可从本页源结构补充，结果带 `source_fallback` 提示。复杂块、未就绪块和无法确定顺序的内容继续提示缺失，不保证还原任意块类型。
- 附件原件只在授权、来源及容量校验通过时保存。权限错误、接口错误页、超限或原生能力缺失时保留“原件未采集”提示。评论、权限配置和历史版本不包含在结果中。
- PDF 保留已采集图片的原始像素，长图按正文宽度连续分段排版；非常宽的 PDF 表格可能按行降级。
- PDF 的 emoji 和符号覆盖有限，缺字会保留原字符并提示；不保证全部 Unicode、任意组合或彩色 emoji 外观。
- DOM 读取不提供协作文档的原子版本快照，持续编辑时需要重新保存核对。
- `/docs/` 已有路由回归，仍需更多真实旧版页面样本。

图片、画板和表格的保存规则与格式差异见 [导出质量规则](docs/export-quality.md)，已完成及后续待办见 [改进状态](docs/export-roadmap.md)。

表格优先保留原列宽比例、单元格底色及水平/垂直对齐；深色底色同时保留文字对比色。PDF 按纸张可用宽度适配，过窄列保留最低可读宽度；单元格自身内容跨页时，垂直对齐按引擎的流式分页处理。样式读取有缓存，复用现有内容复核流程。

## 数据与资源

文档正文、素材、转换和打包留在当前浏览器中，不上传到本项目服务器。本项目没有服务器、统计或遥测。高清图片和附件请求只从已核对归属的当前文档原生配置产生，使用浏览器已有会话；不读取任意页面链接来批量下载。

安装或更新脚本时，油猴会访问 GitHub 下载主脚本和两个静态 PDF 资源。资源 URL 固定到 Git commit，使用 SHA-256 SRI，并在生成 PDF 前再次校验缓存内容。PDF 运行时只读取 `GM_getResourceText` 预缓存，不从网络补拉依赖；缓存缺失或损坏会提示重新安装。页面自身的网络请求以及你主动点击的普通链接由飞书和浏览器处理。

图片、附件、画板、流程图及块树路径通过油猴的 `unsafeWindow` 读取当前页面提供的能力，并核对文档、模型和 DOM 归属。原生接口属于页面内部实现，飞书更新后可能不可用；按对应规则回退或保留缺失提示。脚本不新增账号授权、Token 配置或服务端。

格式选择和圆钮位置使用站点本地偏好；正文及导出文件不写入这些偏好。生成结果保存在页面临时内存，刷新或切换文档后释放。

## 开发与构建

需要 Node.js 22 或更高版本。只保留页内导出的采集、校验、格式生成和保存路径，不包含本地工作台、目录缓存或命令行采集工具。

```sh
npm ci
npm run build
npm test
```

输出为 `lark-doc-exporter.user.js` 和 `飞书文档导出工具-0.0.1.zip`。构建强制检查主脚本体积、固定 commit 资源地址、本地资源摘要及油猴编辑器默认静态规则，自有代码不压缩。也可用 `npm run lint` 单独检查最终脚本；ESLint 仅用于开发，不打入插件。第三方库的合法风格例外限定在各上游模块内，自有代码继续完整检查。

更新 PDF 引擎或字体时，先运行 `npm run build:assets`。校验并提交 `release-assets/` 后，将 `pdf-resource-manifest.json` 指向该提交的固定 URL 和摘要，再构建主脚本。不要删除历史资源提交。资源说明见 [release-assets/README.md](release-assets/README.md)。

解析器 parse5 使用 ES Module 结构；fflate 也用于隔离 Worker 内的解压。为保留模块边界并避免运行时加载代码，相关依赖以内联可读形式构建，产物标明版本与来源；独立 PDF 引擎则使用带 SRI 的静态资源。

源码分工：`userscript/capture.js` 采集与复核页面，`userscript/model.js` 读取本页块树语义，`userscript/native-media.js` 获取受限原生素材，`svg.js` 校验静态矢量图，`importer.js` 校验内存快照，`formats.js` 生成 Markdown/HTML/ZIP，`pdf.js` 定义 PDF 排版，`userscript/pdf.js` 管理缓存资源与可取消 Worker，`userscript/entry.js` 管理浮层和保存流程。

GitHub Actions 已实际通过锁定依赖安装、构建、分发脚本一致性、测试和 lint 检查。具体实现、合成覆盖及真实验收边界见 [改进状态](docs/export-roadmap.md) 和 [发布验收记录](docs/release-checks.md)。
