## 白板静态预览补充验证

修复白板块因未接入图片采集和转换而缺图的问题。只读取唯一、可见的白板内容 Canvas，排除辅助控件层、缩略图和隐藏画布；节点与尺寸稳定且已有像素后输出带背景的 PNG。使用既有图片资产链，不调用飞书接口或增加网络请求。

新增回归覆盖迟挂载、节点替换、透明画布等待、尺寸限制、不可读/无效输出、取消、恢复补采，以及根级、表格、引用中的预览转换。另修复表格画布像素变化但 HTML 不变时的就绪状态缓存。普通图片采集逻辑保持原样。

在已授权样本文档中实际验证：原版无图片且提示白板未转换；修复后每次刷新再连续导出三次，耗时 6.128、5.471、5.177 秒，均无缺失提示。三次 818×1271 PNG 逐字节一致，并进入 Markdown、内嵌 HTML、素材包和实际保存的 PDF。导出 PNG 与独立读取的已渲染内容画布逐字节一致，HTML 离线打开能解码显示。三份 PDF 均为 4 页，提取文本及 90 dpi 逐页渲染一致，目视检查全部 4 页。原始文档、图片、链接、标题和标识未加入仓库。白板预览只表示当前已渲染画面，不声称无限画布的全量或可编辑导出。
