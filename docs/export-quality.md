# 导出质量规则

这些规则用于区分素材字节、显示大小和文档结构。“已交给浏览器保存”表示已发起下载，不证明文件已经写入磁盘。清晰度取决于飞书实际提供的内容，不能从低清位图恢复原本没有的细节。

| 内容 | 采集与保存规则 | 格式边界 |
| --- | --- | --- |
| 普通图片 | 核对当前文档及本块模型后，通过原生图片管理器请求高清资源，保留响应实际返回的 PNG、JPEG、GIF 或 WebP 字节和编码 | 原生高清响应不保证等同于上传原件。只接受受信任的原生来源，不改写 URL 猜测原图；权限、来源、编码或容量校验失败时尝试已加载位图回退 |
| 已加载位图回退 | 等待当前块内唯一、可见图片加载稳定，以 ImageBitmap 的实际像素生成 PNG，避免按经过密度修正的 `naturalWidth` 缩小；源、节点或分辨率变化后复核 | 不支持 ImageBitmap 的环境使用浏览器已加载图片的尺寸。回退保留当前可读画面，不能恢复源文件中未提供的细节 |
| 图片图注、画板说明 | 从已识别的源文本片段按顺序读取，保留已有换行，作为图下说明输出 | 不把通用 alt 或采集方式当作作者图注；未知图注结构、超出预算的内容会提示核对 |
| 飞书画板 | 优先使用本页已加载场景的原始节点边界，复制边界后离屏重绘 PNG，保留明确不透明背景；只接受文档、模型和 DOM 归属相符的本地渲染能力 | 场景倍率最多 2，并在请求前限制像素预算。不包含未加载内容、可编辑节点或交互，PNG 有有限像素 |
| 隔离画板和预览回退 | 主原生渲染失败后，只有隔离代理及原生完整节点边界均可信时才请求 ImageData；检查返回尺寸与完整边界、倍率是否一致，释放正常、迟到及取消时到达的输出 | 缺少可信边界时不调用完整场景代理。其后尝试已有内容层预览重绘，恢复页面样式并标注受限预览；缩略图不能冒充完整原生场景 |
| 流程图（diagram） | 从当前块的原生 `getSvg()` 读取图形，静态校验后保存 SVG 主素材，保留支持的形状、连线及 `foreignObject` 静态 XHTML 标签 | HTML、Markdown 和素材包使用 SVG；PDF 使用同一素材内的白底 PNG 回退，倍率最多 4且先受像素预算限制。不支持的主动内容、外部引用、循环引用或超限结构会明确提示缺图，不删除标签后冒充成功 |
| Markdown、HTML、素材包 | 保留通过校验的实际素材字节；HTML 内嵌图片和附件，Markdown 相对引用，素材包提供独立文件及清单 | HTML 按窗口缩小显示，不减少保存的像素；SVG 的清晰度仍取决于图内内容及阅读器。Markdown 阅读器需要支持所用 SVG、HTML 和内联样式 |
| PDF 图片 | 无需切片的静态 PNG、JPEG 保留已采集资产原字节；GIF、WebP 以原尺寸转静态 PNG；流程图优先使用已采集 PNG 回退，避免 PDF 引擎丢失 XHTML 标签 | GIF 只保留静态帧。长图按整数像素行连续切片并等比排版，不统一压缩到固定最长边；分段会有提示。PDF 使用流程图的位图回退，不承诺该图在 PDF 中保持矢量 |
| 附件原件和视图 | `view` 按已支持子块转换；`file` 从归属相符的原生 token、文件名及下载配置请求原字节，使用当前会话权限。成功原件进入素材及正文链接 | 严格检查 HTTP 状态、来源、重定向、容量及接口错误页，不绕过 403。失败时保留文件名、可用链接及“原件未采集”提示。HTML 可保存内嵌附件，Markdown 使用归档内相对链接；PDF 只显示文件名，不嵌入附件原件 |
| 嵌套列表 | 按块边界递归保留父子层级、混合列表类型、独立起始号及编号重启，父项正文与子项分别转换 | Markdown 使用缩进，HTML 保留列表树，PDF 使用原生列表；字体与标记外观按目标格式排版 |
| Callout | 保留自身文字和内部已支持的标题、图片、代码、表格、列表，按原顺序递归输出为引用块 | 不复刻原文图标及背景装饰；未知子块、缺图与不支持的嵌套表格继续明确提示 |
| 分栏 | `grid/grid_column` 按原文栏序线性展开，各栏内保留已支持的结构；采集合并已知容器内跨视口的子块 | 优先保证正文及阅读顺序，不复刻并排栏宽；子块位置无法确认时提示核对，不盲目追加 |
| 正文表格 | 保留文字、链接、强调、删除线、表题、语义表头及行组、跨行跨列结构；读取列宽比例、底色、对应文字色及水平/垂直对齐 | HTML 保留列宽比例，长串文字在格内换行；PDF 优先使用源比例、缺失时自适应，语义表头跨页重复；极宽表按行展开并提示；带样式或结构复杂的 Markdown 表格使用 HTML |
| 块树辅助复核 | 读取当前文档的有界块树和显式子块顺序，对缺失区域进行有限补采；仅对已就绪、身份匹配、可安全定位的简单源块补充正文 | 补充结果带 `source_fallback` 提示，需要核对外观。复杂块、未就绪块、未知内联组件和位置不明的内容继续提示，不保证从模型还原任意文档 |
| 公式和 Mermaid | 保留已识别原生公式的 LaTeX 源码，以及已识别 Mermaid 插件的带语言代码块 | 普通公式在 Markdown 使用数学定界符，HTML 和 PDF 显示可复制源码；不引入数学排版或 Mermaid 渲染库，不把源码保存描述为图形还原 |
| 时间线和文档提及 | 已识别的时间线插件按原字段顺序输出条目；文档提及保留文字及经过校验的链接 | 不复刻交互时间线外观，不把任意插件当作同一源格式；非法链接不转为可点击内容 |
| PDF emoji 和符号 | 中文常规、粗体字体配合 Noto Emoji 和 Noto Sans Symbols 2 按字素回退；保留原字符及已有文本样式，代码中的 ASCII 继续使用 Courier | 字形覆盖由固定字体版本决定，缺字会提示；不保证全部 Unicode、任意组合或彩色外观。PDF 引擎和四份字体打包为两项油猴预缓存资源，合计约 32.5 MB；非 PDF 导出不解析字体 |

列宽来自原生列轨道，无法读取时只使用可确认的完整无合并行，不平均分摊合并格猜列宽。底色按计算样式逐层合成透明图层；深色格内的代码、引用和链接继承可读前景色。隐藏的合并占位格不作为额外单元格导出。分离渲染的固定表头与正文合并，重复表头只保留一次；原生表头语义进入 thead，PDF 可跨页重复。只保留有限数值、规范色值和对齐枚举，不复制任意 CSS。

表格按目标格式重新排版。PDF 按纸张宽度缩放列轨道，过窄列保留最低可读宽度；单元格自身内容跨页时，引擎会将垂直居中/底部对齐退回顶部流式排版。单元格内多个段落对齐不同的情况使用该格默认对齐，不任选一段覆盖其余段落。固定行高、边框样式和广色域计算色等尚未逐项复刻。DOM 未提供的语义表头不会仅凭颜色推断。表格中的图片仍遵守图片规则，文字保持文字。

带样式的 Markdown 表格依赖阅读器允许 HTML 和内联样式；阅读器过滤样式时，外观可能降级。HTML 文件可直接在浏览器中核对。

位图限制在 8192 像素单边、1600 万像素以内；PDF 另有总像素、输入字节和输出字节上限。场景重绘先按预算选择倍率，不将低清预览插值放大作为原始场景。SVG 只保存重新校验和序列化后的静态内容，单项源内容上限为 2 MiB，另有节点、深度和引用展开预算。

原生素材单项最多读取 24 MiB，超时或取消会停止等待，并中止脚本发起的字节下载。附件一次采集累计最多 48 MiB、128 件，后续快照和文件生成另受总量限制。缓存仅在本次采集生命周期内按文档及 token 复用，最多 48 MiB、128 项，不长期保存失败结果。附件返回 HTML 或 JSON 接口错误时不作为普通原件保存。合法 HTML 附件需原生文件名与类型均相符；JSON 附件需原生文件名或类型明确为 JSON，不宽泛拒绝普通文本中的 JSON 内容。

画板的预览放大、场景重绘与矢量导出是不同路径。飞书原生界面支持 PNG 和矢量 PDF，见[官方画板导出说明](https://www.feishu.cn/hc/zh-CN/articles/553971997356-在画板中导出内容)；官方 CLI 的 SVG 导出需要独立画板读取授权，见[官方实现](https://github.com/larksuite/cli/blob/c5fbf1a52df77d5cb9cac2b1501770b2fb9af7d2/shortcuts/whiteboard/whiteboard_export.go)。本脚本的画板路径读取已加载场景，输出 PNG，不能把流程图的 SVG 支持推及所有画板。页面内部素材接口的公开示例见[开源实现](https://github.com/leemysw/feishu-docx/blob/ce5a23381e814f282e09f3fc15ffda2870a2159e/feishu_docx/core/browser_export/browser_asset_downloader.py)。这些接口不是稳定 OpenAPI，能力不匹配时按对应规则回退或提示。

下载点击未送达或被页面取消时，面板显示失败，并允许重试已有 Blob。成功下载提示报告不代表正文已交付。浏览器接管后的原生保存弹窗、下载进度和取消结果不属于页面可可靠获知的范围。

附件引用对路径段进行 URL 编码，存储名称继续使用安全隔离路径，`#`、`%`、字面量 `%20`、中文与空格不会改变其引用目标。虚拟化补采在每次定位后立即读取；已保存附件按 token/name 核对，全部异步读取结束后再做一次同步复核。变化后重新读取，或剔除旧件并提示，不将身份 token 写入最终附件数据。

图片位图回退的解码等待受剩余期限和取消检查约束；取消或超时后的迟到 bitmap 会释放。同步 Canvas 编码仍按浏览器 API 执行。

PDF 代码块按完整字素选择字体。对有关 emoji、选择符及组合序列，必要时使用 PDF 1.5 的 `ActualText` 标记保留复制文本；不增加字体或修改图像像素。接口适配封装在 `pdf-actual-text.js`，仅作用于当前生成实例，异常及完成时恢复原方法。固定引擎升级时必须重新通过真实引擎的文本、坐标和像素回归；有限字体外观覆盖的边界继续保留。

若引擎明确拒绝超过一页的表头，从原快照重建一次并关闭本次 PDF 全部表格的跨页重复表头，保留内容并说明；正常表格仍重复语义表头。其他错误或恢复失败不循环重试。

正文在交付前记录待下载文件，下载 API 的普通异常也复用该 Blob 重试。提示报告独立显示成败，不覆盖正文生成失败、取消或待下载状态；报告失败也可复用原报告重试。

## 核对方法

1. 先核对素材图片的真实像素尺寸，再核对 HTML、Markdown 使用的图片字节是否一致。
2. 在图片原尺寸与常用阅读比例下检查细线、小字和透明背景；更大文件或更多像素本身不足以证明清晰度提升。
3. PDF 实际保存后检查嵌入图片尺寸、分片顺序和分页，并渲染各页检查可读性与裁切。
4. 表格检查表题、行列数、合并关系、单元格文字和删除线；跨页检查重复表头，宽表检查是否溢出或明确降级。
5. 连续导出时核对图片和文本一致，确认原页面显示尺寸及阅读位置恢复。

本轮浏览器合成验收的 15 项检查通过，覆盖 JPEG、GIF、WebP 原字节，隔离画板 wrapper，图注，公式与 Mermaid 源码，时间线，文档提及，块树排序及有限补全，同名附件和表格。合成检查验证受控场景，不替代真实旧版隔离代理、不同插件源格式或全部飞书文档的验收。真实文档与连续导出的记录见 [发布验收记录](release-checks.md)。

浏览器位图尺寸依据 [WHATWG ImageBitmap](https://html.spec.whatwg.org/multipage/imagebitmap-and-animations.html#dom-createimagebitmap)；PDF 的图片等比布局与表头行为依据 [pdfmake Images](https://pdfmake.github.io/docs/0.3/document-definition-object/images/) 和 [pdfmake Tables](https://pdfmake.github.io/docs/0.3/document-definition-object/tables/)。这些 API 行为不构成对所有文档和浏览器的验证承诺。
